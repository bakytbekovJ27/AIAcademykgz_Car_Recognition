# Распознавание марок автомобилей

Это проект, представляющий собой десктопное приложение для распознавания марок автомобилей на изображениях. Приложение разработано с использованием Python и библиотеки PyQt5 для графического интерфейса.

## О проекте

Приложение использует нейронные сети для выполнения двух основных задач:

1.  **Детекция объектов:** Для нахождения автомобилей на изображении используется предобученная модель RetinaNet с архитектурой ResNet50.
2.  **Классификация изображений:** Для определения марки каждого обнаруженного автомобиля применяется ансамбль из двух моделей:
    *   Кастомная сверточная нейронная сеть (CNN).
    *   Модель, использующая transfer learning на основе архитектуры EfficientNet.

Пользователь может загрузить изображение, после чего приложение обработает его и отобразит результат с ограничивающими рамками и метками, указывающими на предсказанную марку автомобиля и уверенность модели.

**Примечание:** Датасет, использованный для обучения моделей, был собран вручную.

## Установка

1.  **Клонируйте репозиторий с GitHub:**

    ```bash
    git clone https://github.com/bakytbekovJ27/AIAcademykgz_Car_Recognition.git
    cd AIAcademykgz_Car_Recognition
    ```

2.  **Установите необходимые зависимости:**

    ```bash
    pip install torch torchvision opencv-python Pillow PyQt5
    ```

3.  **Скачайте модели:**
    *   Перейдите по [ссылке на Google Drive](https://drive.google.com/drive/folders/1z9SPg47YzIagMLnBrplkPhh0-alJdP_h?usp=sharing).
    *   Скачайте все файлы моделей (`.pt`).
    *   Поместите скачанные файлы в папку `models/` в корне проекта.

## Запуск

Для запуска приложения выполните следующую команду в терминале:

```bash
python main.py
```

После этого откроется главное окно приложения, где вы сможете загрузить изображение для распознавания.

## Обучение моделей

Если вы хотите обучить модели на собственном датасете, вы можете использовать скрипт `train.py`.

```bash
python train.py
```

Скрипт предложит выбрать, какую модель обучать. Ваш датасет должен находиться в папке `dataset/` и иметь структуру, совместимую с `ImageFolder` из PyTorch (с подпапками `train`, `val` и `test`).

## Структура проекта

*   `main.py`: Основной файл для запуска приложения. Содержит код для графического интерфейса (GUI) на PyQt5 и логику взаимодействия с пользователем.
*   `train.py`: Скрипт для обучения моделей классификации.
*   `utils/core.py`: Содержит ядро проекта — функции для детекции автомобилей, предсказания марки и отрисовки результатов. Здесь же определены архитектуры нейронных сетей.
*   `utils/class_id.json`: JSON-файл, который создается во время обучения и содержит сопоставление между ID класса и его названием (маркой автомобиля).
*   `models/`: Папка для хранения обученных моделей. Приложение ожидает здесь найти файлы `model_ft.pt` и `model_tl.pt`.
*   `example/`: Папка с примерами изображений для демонстрации работы приложения.
*   `.gitignore`: Стандартный файл для исключения определенных файлов и папок из контроля версий Git.
*   `GEMINI.md`: Файл с обзором проекта (создан в предыдущем шаге).
*   `README.md`: Этот файл.
